## Using a course setup file

In the Ask AI project, attach the lesson's setup file and say:

> Read my brain, then follow this setup file. Guide me through its questions and testing. Commit my finished personalized employee profile to Employees, reference my shared context, and tell me what has and has not been connected or tested.

The setup file guides the interview. The output is your personal employee profile. Keep using that profile for future tasks; do not repeat the original interview unless you want to reconfigure the employee.

An employee profile explains the job. It can refer to reusable methods in Skills and current work in Projects. Example filenames are Personal-Assistant.md or Content-Strategist.md; these examples are not installed employees.

Use _Employee-Profile-Template.md only if you need a starting outline. The detailed course setup file takes precedence when it requires more sections. Add one short line here for each actual employee you create.
