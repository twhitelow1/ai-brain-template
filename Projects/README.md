# Your projects

Create a project folder for ongoing work, such as a website launch, a campaign or a client presentation. Do not create one for every quick question.

Ask Ask AI:

> Set up a project for [goal]. Ask for the information you need, create a brief and handoff in my brain, and keep the project files there.

_Project-Template is empty scaffolding, not an active project. Copy its two files into the new project folder and personalize them.

- BRIEF.md: goal, audience, requirements, source locations and current decisions.
- HANDOFF.md: status, actual outputs, open issues and next step.
- Other text files: drafts, scripts and outlines for this project. Large or binary deliverables stay in their working home and are linked from HANDOFF.md.

Keep ordinary personal and work context in Context. Link to it rather than duplicating it. Ask AI reads the current project files before making changes; git history preserves approved versions.
