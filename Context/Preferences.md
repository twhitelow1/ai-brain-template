## How to update

For each meaningful preference, state the rule, its scope and when the user confirmed it. Example structure, not a user preference: "Preference: [rule]. Applies to: [scope]. Confirmed: [date]."

Task-only feedback belongs in the relevant project. If the user changes a preference, update the active rule rather than leaving contradictory rules side by side. Ask when the scope or intended correction is unclear.
